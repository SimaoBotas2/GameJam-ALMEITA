# Virus

Repo para a gamejam do Almeita Games 2026.

O jogo começou como um projeto de gamejam, mas o objetivo agora é acabá-lo como jogo completo. É um jogo 2D top-down feito em Godot 4.6, ambientado num hospital, onde controlamos a personagem SIH e resolvemos puzzles pelas salas.

As cenas level_1, level_2 e level_3 são legacy, mantidas só como referência — o desenvolvimento atual continua a partir de room_1 em diante.
